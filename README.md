# Folder Camera

Folder Camera превращает Android-телефон в фотоаппарат, который автоматически передаёт снимки в выбранную папку на компьютере Windows. Приложение сохраняет структуру подпапок, позволяет обрезать и повернуть снимок перед сохранением и работает в локальной сети без доступа к интернету.

Этот репозиторий — русскоязычный форк проекта **sigmaSd/folder-camera**. Изменения форка перечислены ниже. Исходный проект распространяется по лицензии GPL-3.0-or-later, авторство и уведомления о сторонних компонентах сохранены.

## Скачать и установить

Сборка 29 проверена пользователем в работе и принята как стабильная. Комплект опубликован с исходными именами файлов.

| Платформа | Файл | Установка |
| --- | --- | --- |
| Android 8 и новее | [folder-camera-test.apk](https://github.com/Aleks1496/folder-camera/releases/download/folder-camera-build-29/folder-camera-test.apk) | Установите APK на телефон, разрешив установку из выбранного источника |
| Windows 10/11 x64 | [folder-camera-receiver-windows-x64.zip](https://github.com/Aleks1496/folder-camera/releases/download/folder-camera-build-29/folder-camera-receiver-windows-x64.zip) | Распакуйте весь архив и запустите `FolderCameraReceiver.exe` |
| Проверка файлов | [SHA256SUMS](https://github.com/Aleks1496/folder-camera/releases/download/folder-camera-build-29/SHA256SUMS) | Сравните SHA-256 скачанных файлов с опубликованными значениями |

APK сборки 29 создан вариантом `debug`, имеет идентификатор `io.github.sigmasd.foldercamera.debug` и версию `1.0.5-dev`. Статус стабильного релиза подтверждает пригодность именно этого проверенного комплекта. Для обновления установленной сборки 29 используйте совместимые APK этого форка с тем же идентификатором и подписью. Подписанные сборки варианта `release` имеют отдельный идентификатор `io.github.sigmasd.foldercamera`.

В архиве Windows лежат два необходимых исполняемых файла. `FolderCameraReceiver.exe` отвечает за окно и значок в трее, `FolderCameraEngine.exe` принимает и сохраняет снимки. Храните их в одной папке. Интерфейс использует Windows Forms и встроенный в Windows .NET Framework, движок включён в комплект. При установке на рабочий компьютер доступны все необходимые компоненты, включая генерацию сертификата и QR-кода. MSI и Windows ARM64 в комплект этого форка не входят.

## Быстрый старт

1. Подключите телефон и компьютер к одной локальной сети. При подключении телефона по Wi-Fi проверьте, что выбранная сеть позволяет обращаться к компьютеру.
2. Запустите `FolderCameraReceiver.exe` и дождитесь статуса «Готов к приёму».
3. Выберите папку сохранения на ПК. При первом запуске используется папка `Captures` в профиле пользователя.
4. В Android выберите основную папку через системный диалог и укажите относительный путь для снимков, например `Работа/Объект 1`.
5. В приёмнике создайте код подключения. На телефоне откройте «Настройки → Подключить приёмник» и отсканируйте свежий QR-код.
6. Включите «Синхронизация с ПК». На Android 17 и новее предоставьте приложению разрешение доступа к локальной сети.
7. Сделайте снимок, при необходимости обрежьте или поверните его и нажмите «Сохранить».

Для пути `Работа/Объект 1` приёмник создаст соответствующие подпапки внутри основной папки на ПК. Снимок сначала сохраняется и проверяется на телефоне, затем передаётся на компьютер. После подтверждения приёма он получает статус «Доставлено».

Телефон также работает самостоятельно. Для съёмки и сохранения в выбранную папку подключение к приёмнику можно оставить выключенным.

## Съёмка и редактирование

После съёмки открывается экран редактирования. Начальная рамка обрезки отступает на 5% от краёв, чтобы её углы было удобно захватить. Рамку можно перемещать и изменять за углы, а кнопка «Сбросить рамку» выделяет весь снимок.

Кнопки 0°, 90°, 180° и 270° задают поворот относительно исходного изображения с учётом ориентации камеры. Если рамку ещё не меняли, выбор поворота выделяет весь кадр. Уже выбранная область поворачивается вместе со снимком. В файл записывается результат, соответствующий предпросмотру, затем он сохраняется и передаётся на ПК. Отмена возвращает к камере.

Системная кнопка и жест «Назад» на экране камеры возвращают на основной экран выбора папки. На камере также доступна кнопка «Сменить папку».

## Передача и удаление с телефона

Синхронизация по умолчанию применяется к следующим снимкам. Для передачи уже сохранённых снимков при включении синхронизации можно выбрать существующие папки.

При недоступном компьютере приложение сохраняет снимки на телефоне и оставляет задания в очереди. Повторные попытки используют задержку. Кнопка «Повторить отправку» позволяет заново отправить снимки после устранения ошибки. Фоновые попытки зависят от планировщика Android.

В разделе «Настройки → Передача по локальной сети» есть переключатель **«Удалять фото с телефона после передачи»**. По умолчанию он выключен. После включения копия на телефоне удаляется после проверки квитанции о сохранении на ПК. Настройка применяется к передачам, подтверждённым после её включения. История доставки сохраняется, папки на телефоне остаются. Перед удалением приложение сверяет размер и SHA-256 файла. Если локальную копию изменили или хранилище отказало в доступе, приложение показывает ошибку и позволяет повторить удаление. Незавершённое удаление возобновляется после перезапуска при включённой настройке.

В Windows существующая подпапка используется при совпадении имени без учёта регистра. Например, путь `samsung/работа` на телефоне сохраняет снимки в уже существующую `SAMSUNG/РАБОТА` на ПК. Это правило действует для каждого уровня пути. Файл с занятым именем защищён от перезаписи.

## Приёмник Windows и работа в трее

Окно позволяет начать и остановить приём, выбрать и открыть папку, создать QR-код, отключить телефон и просмотреть список последних снимков.

С включённым флажком «Продолжать приём после закрытия окна» крестик скрывает окно и оставляет приём работающим. Одинарный или двойной щелчок по значку в трее возвращает окно. Правый щелчок открывает меню с командами «Открыть приёмник» и «Выйти из приёмника». Полностью завершить работу можно командой выхода.

Опция «Запускать при входе в Windows» запускает приёмник в фоне при входе текущего пользователя. Настройки и сопряжённые телефоны хранятся в `%LOCALAPPDATA%\FolderCamera`. Сохраняйте эту папку при обновлении приложения.

Приёмник автоматически выбирает частный сетевой адрес. Поддерживается внешний интерфейс Hyper-V вида `vEthernet (sw)`, внутренние интерфейсы Default Switch и WSL исключаются. При смене сети приложение повторно проверяет адрес. Телефон хранит адрес, полученный при сопряжении. Новый адрес можно ввести в Android и подтвердить кнопкой «Проверить и обновить адрес».

При необходимости можно явно задать параметры запуска.

```powershell
.\FolderCameraReceiver.exe --root "C:\Фото" --bind 192.168.1.10 --port 8443
```

Параметры `--root`, `--bind` и `--port` запоминаются. `--bind auto` возвращает автоматический выбор адреса. Параметр `--state` позволяет выбрать отдельную папку состояния.

## Работа в изолированной локальной сети

Съёмка, редактирование, создание QR-кода, сопряжение, передача, проверка файлов и управление приёмником выполняются локально. Телефон использует доступный Wi-Fi или Ethernet и может передавать данные в сети без подтверждённого доступа к интернету. Для локальной передачи используется прямое подключение, включая обход системного HTTP-прокси.

Интернет нужен для скачивания комплекта, получения обновлений и первоначальной подготовки среды сборки. APK и архив приёмника можно перенести на устройства с локального носителя. Проверка обновлений Android запускается вручную по кнопке в настройках и обращается к Releases этого форка. Обновление Windows выполняется заменой распакованного комплекта после выхода из приёмника.

Приёмник слушает выбранный локальный адрес и обычно использует порт 8443. Если порт занят, при автоматическом выборе может использоваться следующий свободный. Ориентируйтесь на точный HTTPS-адрес из окна.

Если Android сообщает «ПК недоступен», проверьте сеть Wi-Fi, IP и порт приёмника, VPN и разрешение входящих подключений Windows для `FolderCameraEngine.exe`. У второго компьютера своё правило брандмауэра. Гостевая сеть Wi-Fi или изоляция клиентов могут запрещать связь между устройствами. Внешний доступ к приёмнику для локальной передачи не требуется.

## Сборка из исходников

### Android

Нужны JDK 21, Android SDK с платформой 37.0 и Build Tools 36.0.0. Gradle Wrapper находится в репозитории.

```sh
sdkmanager 'platforms;android-37.0' 'build-tools;36.0.0' 'platform-tools'
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon --max-workers=4
```

Путь к SDK задаётся через `ANDROID_HOME` или `sdk.dir` в `android/local.properties`. APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`. Файлы схем Room находятся в `android/app/schemas`.

В workflow ветка master публикует `folder-camera-test.apk`. Для подписанной сборки по тегу `folder-camera-vX.Y.Z` используются секреты `FOLDER_CAMERA_KEYSTORE_BASE64`, `FOLDER_CAMERA_STORE_PASSWORD`, `FOLDER_CAMERA_KEY_ALIAS` и `FOLDER_CAMERA_KEY_PASSWORD`. Такой тег запускает отдельную сборку варианта `release`.

### Windows x64

Нужны Windows x64, Python 3, Deno 2.9.7 и компилятор .NET Framework из Windows. Выполните из корня репозитория.

```powershell
python scripts/build_windows_receiver.py .work/artifacts/folder-camera-receiver-windows-x64.zip
```

Скрипт собирает встроенный движок через `deno compile`, окно Windows Forms через `csc.exe` и упаковывает EXE и лицензии в ZIP. Первоначальная подготовка зависимостей выполняется на машине сборки.

### Проверки и CI

Основной workflow форка находится в `.github/workflows/fork-release.yml`. Android собирается на Linux-раннере с метками `self-hosted, linux, folder-camera`, Windows — на `self-hosted, windows, x64, folder-camera-windows`. GUI-проверки готового Windows-комплекта выполняются на отдельном раннере `folder-camera-windows-gui` в интерактивном сеансе.

```sh
cd receiver
deno task check
deno task lint
deno task test
```

Для проверки готового Windows-архива в интерактивном сеансе выполните из корня репозитория.

```powershell
python scripts/smoke_windows_receiver.py .work/artifacts/folder-camera-receiver-windows-x64.zip
```

Проверка использует отдельный временный профиль, локальный HTTPS, тестовый JPEG и события трея. Android-инструментальные тесты находятся в `android/app/src/androidTest`, JVM-тесты — в `android/app/src/test`.

Запись `release/stable.json` определяет проверенную сборку, которую workflow `.github/workflows/promote-stable.yml` помечает стабильной. При повышении статуса проверяются коммит и хеши вложений. Файлы выбранной сборки сохраняются, а описание релиза становится русскоязычным. Автоматические сборки master продолжают публиковаться как предварительные.

## Хранение данных и дополнительные материалы

Приёмник хранит настройки, идентификатор, сертификат, ключи и квитанции в папке состояния. Папка состояния и папка снимков должны быть отдельными, без вложения друг в друга. Служебная папка `.folder-camera-partials` внутри папки снимков используется для незавершённых передач. Доступ к этим папкам должен оставаться у доверенного пользователя компьютера.

Android запрашивает доступ к выбранной пользователем папке через системный механизм SAF. Сохранение проверяется по размеру и SHA-256. При ошибке сохраняется временная копия и доступна повторная попытка. Смена основной папки применяется к новым сеансам. Для восстановления старых сохранений предоставьте доступ к исходной папке.
